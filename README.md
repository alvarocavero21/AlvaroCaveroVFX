# Alvaro Cavero VFX — Portfolio Website

Personal portfolio website for Alvaro Cavero, VFX Artist specializing in Houdini, Karma, Maya, and Unreal Engine.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion, Lenis (smooth scroll)
- **Media**: React Player

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm run start
```

## Deployment

Optimized for deployment on [Vercel](https://vercel.com). Connect the GitHub repository and Vercel will auto-deploy on every push to `main`.

## Project Structure

```
app/          # Next.js App Router pages and layouts
components/   # Reusable React components
public/       # Static assets (images, videos, fonts)
```
